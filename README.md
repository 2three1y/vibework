# Vibework

Vibework is a living index of mainstream, niche, new, regional, and decentralized social networks.

Live site: https://vibework.pages.bu.app/

## Features

- Search the catalog by name, category, or description
- Browse category tabs, including niche, new wave, decentralized, and mainstream
- Open every listed network from its visible link
- Expand a what-you-can-do description on every card
- Try local additions with the submit button

## Run it

Open `index.html` in any modern browser. There is no build step and no server required.

## Update it

Edit the `networks` data in `index.html`, then republish the same file to the Vibework page. The public address stays the same while the catalog changes. This is a static single-file site, so GitHub commits do not automatically publish by themselves yet.

## Contributing

Add networks with a working official URL, a short description of what people do there, and a useful category. Prefer independent, niche, regional, open, and new communities while keeping the major platforms represented.
